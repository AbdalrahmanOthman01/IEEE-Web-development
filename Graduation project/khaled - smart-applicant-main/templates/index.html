How the Matching Algorithm Works

Mathematical & Machine Learning Foundations for Graduation Defense

1. TF-IDF Vectorization (Term Frequency - Inverse Document Frequency)

Measures how important a keyword is to a document relative to the corpus. Frequently occurring common words (e.g., "the", "and") are penalized, while specialized technical skills (e.g., "Python", "SQLAlchemy", "Tailwind") receive high numerical weights.

TF-IDF(t, d, D) = TF(t, d) × log(N / DF(t))

2. Cosine Similarity (حساب التشابه الجيبي)

Calculates the cosine of the angle between the multi-dimensional vector representing the Resume and the vector representing the Job Description. The result is invariant to document length:

Cosine Similarity = (A · B) / (||A|| × ||B||)

A value of 1.0 (100%) indicates identical directional orientation in the feature space, while 0.0 (0%) denotes no shared technical vocabulary.

3. Gap Analysis & Ranking

Missing keywords are ranked strictly by their TF-IDF weight in the job description so candidates are prompted to address the most decisive qualifications first.
